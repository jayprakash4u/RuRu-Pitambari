# Ruru Pitambari website

Production-ready Next.js App Router foundation for the Ruru Pitambari website. No customer-facing pages have been designed yet.

## Structure

- `src/app` — App Router composition; Server Components by default
- `src/features` — isolated business capabilities with public APIs
- `src/components/ui` — centralized shared UI primitives
- `src/env` — validated client and server environment variables
- `docs/ARCHITECTURE.md` — boundaries and dependency rules
- `docs/DESIGN_SYSTEM.md` — brand, visual, content and accessibility rules
- `src/styles/tokens.css` — primitive and semantic design tokens
- `src/styles/reset.css` — accessible global baseline
- `src/styles/typography.css` — approved text styles
- `src/styles/layout.css` — containers, sections and layout primitives
- `src/styles/components.css` — buttons, cards, fields and badges
- `src/styles/index.css` — single stylesheet entry point
- `src/assets/brand/logo-source.png` — supplied source logo reference

## Commands

```bash
npm run dev
npm run typecheck
npm run lint
npm run format:check
npm run validate
```
